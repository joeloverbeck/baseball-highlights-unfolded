Use one domain context. Read [the competitive rules](../foundation/rules.md) for Lineup, Dugout, On Deck, In Play, Minor Leagues, threatened hits, Save and Buy Round. Read [the expansion requirements](../foundation/expansions.md) for card-specific qualifications.

Read the root `GLOSSARY.md` and relevant decisions in `docs/adr/` when present. Continue with the foundations when these paths are absent. Create the glossary when a term warrants recording and the ADR directory when the first decision warrants an ADR. Surface conflicts with existing ADRs before proposing a different decision.

Use printed terms in specs, UI and agent observations. Update the relevant foundation when a ruling changes.
